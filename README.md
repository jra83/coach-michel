# Coach Michel - Frontend PWA

Interface PWA pour Coach Michel, le coach IA pour l'entraînement running.

## Installation

```bash
cd /home/debian/coach-michel
npm install
```

## Développement

```bash
npm run dev
```

L'application sera accessible sur http://localhost:3000

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Fonctionnalités

- ✅ Métriques de courses passées
- ✅ Résumés analytiques
- ✅ Plan d'entraînement
- ✅ Données corporelles (poids, graisse, muscle, eau)
- ✅ Chat avec Coach Michel
- ✅ PWA (offline, installable)
- ✅ Mobile-first responsive design

## Stack technique

- React 18
- Vite
- Tailwind CSS
- React Router
- Axios
- Vite PWA

## API Backend

L'application se connecte à l'API backend sur http://localhost:5000
